Buy audio description as a defined service: a script explaining essential visuals, suitable narration, an agreed audio mix, and a delivery format your player can actually present. Captions alone do not supply that visual information. Commission a short specimen and listener review before accepting a general promise that the video will be accessible.

## Identify the information missing from the soundtrack

Listen to the existing video without relying on the image. Note which actions, relationships, on-screen words, or scene changes are necessary to understand the content but are absent from the audio.

This is an initial purchasing exercise, not a substitute for specialist description work. Your role is to identify important business meaning: a screen changes from pending to approved, a chart compares two categories, or a person silently demonstrates a required step.

[W3C's guidance on visual description](https://www.w3.org/WAI/media/av/description/) explains that description communicates essential visual information, including displayed text. It also describes separate-file approaches that depend on media-player support.

Avoid requesting a narration of every visible detail. Decorative information can compete with dialogue and useful sound. Ask the supplier how it prioritizes what a listener needs to understand, and provide context for visual elements whose meaning is not obvious to an outside describer.

## Compare the actual service components

A quote labeled “audio description” may include different combinations of scriptwriting, review, voice recording, mixing, and file preparation. Ask the vendor to itemize what it supplies and what your editor must do.

[3Play's service explanation](https://www.3playmedia.com/platform/audio-description/) describes a workflow of scripting essential visuals, recording with a narrator or synthetic voice, and mixing the description with the video. That establishes concrete components to ask about, not proof that any particular quote includes every output you need.

Request a sample of the proposed voice and description style. Evaluate whether it is intelligible and distinguishable from existing narration without becoming distracting. If a synthetic option is offered, ask how pronunciation and performance corrections are reviewed.

Clarify whether the vendor works from a locked final cut. Changes to picture timing can affect description placement even when the business's spoken script remains unchanged. Make the current source version part of the order.

## Create an audio-description order specimen

Use the following original worksheet to brief a short paid specimen. Example moments are illustrative.

| Visual moment | Meaning not in existing audio | Available space | Requested check |
| --- | --- | --- | --- |
| Status changes on screen | The request is now approved | Brief pause after explanation | State the meaningful change clearly |
| Silent comparison chart | One option includes a feature the other lacks | Narration overlaps chart | Propose a concise alternative placement |
| Demonstration step | User selects a specific control | Pause before next instruction | Identify the action without excess detail |
| End card | Contact method appears only as text | Music continues | Include the necessary contact information |
| Speaker appears | Identity matters to the statement | Opening gap | Describe or identify appropriately |

Ask the supplier to return the proposed script with timing notes, the audio specimen, and a description of the delivery format. Have the business reviewer confirm factual details and an accessibility-informed reviewer assess usefulness.

If the existing soundtrack leaves insufficient space, ask for options and their consequences. Do not simply instruct the narrator to speak faster until every word fits. A separate described version or a change to the primary narration may be more appropriate.

## Check the delivery route before ordering the full film

Name the actual destination player, website, or platform. “MP4 delivery” is not enough to establish whether users can select an alternate track or find a separate described version.

Ask the vendor and the person responsible for publication to demonstrate the intended route with the specimen. Can a listener locate the described version? Does the player expose the required control? Does the selection persist or reset in a confusing way?

A separate audio file sitting in a handoff folder is not an accessible user experience by itself. Conversely, a mixed described video can be useful when the publishing setup supports a clear alternative-version link.

Test the chosen approach on the devices and access methods relevant to the audience. Record the exact file and player configuration that worked. This is an acceptance requirement for the purchase, not a broad promise that one format works everywhere.

## Run a focused listener acceptance session

Include people who use description or a qualified accessibility reviewer in the sample evaluation, with appropriate compensation for their contribution. Give them the finished access path rather than explaining all the visual information in advance.

Ask what they understood about the important actions, displayed information, and sequence. Record moments where description collides with dialogue, identifies something too late, or leaves a necessary relationship unclear.

Separate factual errors from description-quality concerns and playback failures. A wrong feature name needs source correction; an overly dense sentence needs script revision; a missing player control needs a delivery fix. Naming the category helps avoid sending every issue back to the narrator.

Do not treat a single positive reaction as a universal accessibility certification. The session supplies evidence about the specimen and helps define acceptance conditions for the full order. If a contractual standard or legal obligation applies, obtain the relevant specialist assessment separately.

## Write the order around usable deliverables

Specify the final source version, description script, voice choice, pronunciation references, mix requirements, file formats, and delivery route. Name who approves factual content, who assesses description quality, and who verifies playback.

Ask for the vendor's correction terms and a schedule that includes your reviews. Distinguish a correction to an agreed description from reworking it after the picture changes. Request actual pricing for the defined scope rather than applying a generic per-minute assumption.

At delivery, reconcile the files against the order. Check that the approved script corresponds to the final recording, that description is present where expected, and that the published access route still works.

Keep captions and other accessibility outputs in the broader project scope without treating them as interchangeable services. The buying decision here is complete when essential visual meaning is communicated through the delivered experience and the responsibilities for unresolved issues are clear.
